## Selected projects

* **[Electricity Price Trends in Europe](https://github.com/MaximilianDieringer/WU_Vienna_energy_market_analysis)**: Data Science Lab with Marbl FlexCo, clustering of daily price profiles and day-ahead forecasting. My part: cluster analysis.
* **[Breast Cancer Detection](https://github.com/MaximilianDieringer/breast-cancer-detection)**: cross-dataset classification of mammograms with EfficientNet-B0 and ResNet-50 (PyTorch). Team project with Harald Körbel.
* **[SkinGuard](https://github.com/MaximilianDieringer/START-Munich-4fun)**: AI app for a first assessment of skin irritations, built at the START Munich Hackathon 2025. My role: idea, dataset research, pitch and UX prototype.
* **[Bluesky Hate Speech Detection](https://github.com/MaximilianDieringer/bluesky-hate-speech-detection)**: Apache Spark pipeline that predicts hate speech scores for Bluesky posts.
